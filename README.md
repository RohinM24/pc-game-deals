# PC Game Deals

A PC game deals website built using HTML, CSS and JavaScript.

## Features

- Search games by title
- Filter games by store
- Sort games by price, discount and title
- Wishlist functionality using localStorage
- Dashboard statistics
- Live PC game deals using the CheapShark API
- Live deal filtering and pagination
- Responsive layout and animations

## Technologies

- HTML
- CSS
- JavaScript
- CheapShark API

## Running the Project

Open the project in Visual Studio Code and run `index.html` using Live Server.

An internet connection is required for the live deals section.
